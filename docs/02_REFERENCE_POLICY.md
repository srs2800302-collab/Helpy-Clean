# Helpy — использование старой реализации

Старая реализация находится вне нового репозитория и используется только для чтения.

## APPROVED_REQUIREMENT

Подтверждённое действующее требование.

Может быть заново документировано и реализовано после проверки актуальности.

## REFERENCE_DATA

Данные, бизнес-смысл которых требуется новой системе.

Schema, contracts и способ хранения проектируются заново.

## LEGACY_IMPLEMENTATION

Код, архитектура, CI, build/deployment configuration, API, database, UI и infrastructure scripts старой системы.

Не переносится в новую реализацию.

## Запрещённое наследование

Запрещены:

- Git history старой реализации;
- clone старого репозитория как новая база;
- Git worktree;
- submodule;
- subtree;
- symlink;
- копирование старых application directories;
- копирование CI и build/infrastructure configuration.

## Правило переноса

Перед использованием требования:

1. определяется authoritative source;
2. подтверждается актуальность;
3. бизнес-смысл отделяется от legacy implementation;
4. требование документируется заново;
5. реализация создаётся по новой архитектуре.

Legacy behavior не имеет приоритета над утверждённым требованием.
